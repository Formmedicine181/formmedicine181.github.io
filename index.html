🧐 What is irwhois?

irwhois is a simple but powerful tool that checks whether a .ir domain (like example.ir) is available for registration or already taken. It talks directly to the official Iran NIC WHOIS server (whois.nic.ir)to fetch real-time status.

Whether you're a website owner, SEO professional, or just curious about a domain name, irwhois gives you the answer in seconds —no complex commands, no sign-ups, no cost.

⚙️ How It Works

  1. You enter a domain name (e.g., mysite.ir).
  2. irwhois sends a WHOIS query directly to whois.nic.ir.
  3. The official NIC responds with registration details or an "available" flag.
  4. irwhois displays the result immediately — with color-coded output.
